📁 ARQUIVOS CRIADOS:
------------------------------------------------------------
✅ robots.txt         - Controla crawlers de busca
✅ sitemap.xml        - Mapa do site para Google/Bing
✅ manifest.json      - Configuração PWA (instalar no celular)
✅ humans.txt         - Informações sobre o site
✅ llms.txt           - Informações para IAs (ChatGPT, Claude, etc.)
✅ _headers           - Cache e segurança
✅ security.txt       - Contato de segurança
